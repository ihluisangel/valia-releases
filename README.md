# Valia Food · Descargas

Instaladores oficiales de **Valia Food** para Android y Windows.

## Descargar la última versión

| Plataforma | Descarga |
|---|---|
| Android | [valia-food.apk](https://github.com/ihluisangel/valia-releases/releases/latest/download/valia-food.apk) |
| Windows | [valia-food-windows.zip](https://github.com/ihluisangel/valia-releases/releases/latest/download/valia-food-windows.zip) |

Todas las versiones anteriores están en [Releases](https://github.com/ihluisangel/valia-releases/releases).

> Las versiones marcadas como **Pre-release** son de prueba y se conectan a un
> servidor de pruebas. No las uses para operar tu restaurante.

## Instalación en Android

1. Descarga `valia-food.apk` desde el teléfono.
2. Ábrelo. Si Android lo pide, permite **Instalar apps desconocidas** para tu
   navegador o gestor de archivos.
3. Pulsa **Instalar**.

Para actualizar, descarga la versión nueva e instálala encima: tus datos se
conservan.

## Instalación en Windows

1. Descarga `valia-food-windows.zip`.
2. Descomprímelo en una carpeta, por ejemplo `C:\Valia Food`.
3. Abre `valia_food_app.exe`.
4. Si aparece **"Windows protegió su PC"**, pulsa **Más información** →
   **Ejecutar de todas formas**.

Para actualizar, cierra la app y reemplaza el contenido de la carpeta por el
del nuevo `.zip`.

## Requisitos

- Android 7.0 o superior.
- Windows 10 u 11 de 64 bits.
- Conexión a internet para sincronizar con el servidor.
